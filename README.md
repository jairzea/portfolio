# Portafolio · Jair Zea Páez

Sitio personal. React + TypeScript sobre Vite, Tailwind v4 y Motion para animación.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

Todo el contenido (proyectos, experiencia, stack) vive en `src/data.ts`. Editar ahí, no en los componentes.

## Publicar

El sitio se sirve desde la rama `gh-pages` (Settings → Pages → Deploy from a branch → `gh-pages` / root).
Para publicar cambios:

```bash
npm run deploy
```
